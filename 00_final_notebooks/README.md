# Финальные ноутбуки и результаты

Прогноз направления следующего часа для BTC/USDT, торговый слой поверх вероятностей, бэктест с
комиссией и обучение с подкреплением (FinRL / Stable-Baselines3). Каталог содержит восемь рабочих
ноутбуков. Каждый следующий проверяет одну новую идею поверх предыдущего.

## Общий протокол

Он одинаков во всех ноутбуках, поэтому их метрики можно сравнивать напрямую.

- **Данные.** Часовые свечи `data/btc_1h.csv` с 2021-01-01 по 2026-09-28. Новости `data/btc_news.csv`
  заканчиваются 04.06.2025, поэтому обучение, отбор признаков, подбор гиперпараметров и валидация
  используют только цены до этой даты.
- **Разбиение.** train / test / validation = 70% / 15% / 15% ряда; `dev` = train + test.
  Кросс-валидация — `TimeSeriesSplit` на 5 фолдов с embargo.
- **Валидация** — 08.10.2024 — 04.06.2025, 5 740 баров. Buy & hold за это время: **net +67.8%,
  Sharpe 1.79, просадка −31.0%**. Окно растущее, поэтому само по себе плохо различает стратегии.
- **Walk-forward (WF)** — шесть окон по 45 дней после конца новостей. Ни одна модель не видела эти
  данные ни на одной стадии. Окна выбраны по ярко выраженному режиму рынка:

  | окно | период | buy & hold |
  |---|---|---|
  | бычий | 2025-06-04 — 2025-07-19 | +11.7% |
  | боковой | 2025-08-06 — 2025-09-20 | +1.6% |
  | медвежий | 2025-10-08 — 2025-11-22 | −30.5% |
  | медвежий-2 | 2026-01-15 — 2026-03-01 | −30.9% |
  | боковой-2 | 2026-06-13 — 2026-07-28 | −0.2% |
  | бычий-2 | 2026-08-13 — 2026-09-27 | +32.6% |
  | **среднее** | | **−2.6%** |

  Окна 4–6 добавлены после обновления файла цен 28.09.2026. Для правил выхода, придуманных до этого
  обновления, они — полностью независимая проверка. В WF проверяются только табличные модели, их
  ансамбль, FinRL и (в версии с LSTM) LSTM: веса остальных нейросетей ноутбуки не сохраняют.
- **Издержки.** Комиссия 0.10% с каждой сделки. Не моделируются спред, проскальзывание сверх гэпа
  на открытии и фандинг perpetual-фьючерсов.
- **Правила выхода и торговый слой выбираются только на dev** (OOF фолдов 1–4) с ограничениями
  активности: минимальный оборот, экспозиция, прибыльность в 3 из 5 подпериодов.
- **Воспроизводимость.** После обновления данных все ноутбуки перепрогнаны. Supervised-часть, FinRL
  и RL-позиция воспроизводятся до знака; модели последовательностей — с шумом GPU в 4-м знаке.
  Мета-агент «RL на вершине ансамбля» неустойчив: от этого шума его net на валидации в одном
  ноутбуке менялся с +39.1% до +7.0%.

### 1. `01_final_ensenble.ipynb` — базовый конвейер

**Идея.** Довести конвейер ДЗ №3–№6 до финального вида и добавить к нему RL.

**Что внутри.**
- **Признаки.** 331 признак: технический анализ, свечные паттерны и паттерны разворота, аномалии,
  Фурье, вейвлеты, CWT, 24 новостных признака (FinBERT, MiniLM + PCA, интенсивность потока). Отбор
  через тени оставляет 18.
- **Модели.** LogReg, дерево, CatBoost (Optuna, 25 попыток каждая), TimesNet, TSMixer, TimesFM 2.0.
- **Торговый слой.** Вероятность → позиция: режимы `always / hold / flat / ramp / long_flat /
  scaled`, сглаживание, ребалансировка; пороги — только по прошлым фолдам.
- **Ансамбли.** «Ансамбль» (3 табличные модели) и «Ансамбль+» (все 6 моделей).
- **RL.** FinRL `StockTradingEnv` (5 алгоритмов), своя позиционная среда (PPO/SAC), мета-агент
  на вершине ансамбля; у всех ограничение частоты решений.
- **Оценка.** Walk-forward по шести окнам.

**Стратегии и результаты.**

| стратегия | валидация: net / Sharpe / просадка | WF среднее |
|---|---|---|
| CatBoost (2 сделки, почти buy & hold) | **+84.1% / 2.06 / −31.0%** | −3.6% |
| RL на вершине ансамбля | +56.0% / 1.84 / −23.0% | не проверялся |
| RL-позиция (PPO) | +55.1% / 1.86 / −25.8% | не проверялся |
| TimesFM | +7.3% / 0.52 / −18.0% | не проверялся |
| LogReg / дерево | −0.1% / −1.4% | −3.6% / −10.4% |
| FinRL (TD3) | −2.4% / −0.07 / −17.4% | −0.2% |
| Ансамбль+ (6 моделей) | −4.7% / 0.12 / −31.1% | не проверялся |
| Ансамбль (3 модели) | −15.1% / −0.22 / −40.7% | −3.7% |
| TimesNet / TSMixer | −27.7% / −64.1% | не проверялись |
| HW2 baseline / ТА всегда в рынке | −95.3% / −95.8% | −53.9% / −53.7% |

**Вывод.** Модели в основном держат длинную позицию: зарабатывают на росте и теряют на падении.
В обоих медвежьих окнах в плюсе ни одна стратегия из восьми. Новости дают один выживший
признак (`news_count_168`) и статистически незначимый эффект. RL с ограничением частоты прибылен
на валидации, но это растущее окно, а в WF RL-позиция не проверялась.

### 3. `03_final_ensenble_with_sltp.ipynb` — стоп-лосс и тейк-профит

**Идея.** Закрывать сделку не только по сигналу модели, но и внутри часа по стопу или тейку от цены
входа: гэп исполняется по open, внутри часа первым считается стоп. Правила выхода подбираются
совместно с торговым слоем: 288 сигналов × 49 вариантов выхода, внутри целевой функции Optuna.
Раздел 24.1 сравнивает пять правил выбора стопов.

**Стратегии и результаты** (среднее четырёх табличных стратегий в WF).

| правило | WF среднее | медвежий / медвежий-2 | бычий-2 | окна 4–6 |
|---|---|---|---|---|
| без стопов | −2.8% | −25.0% / −26.8% | +26.9% | −0.4% |
| подбор (раздел 14) | −3.1% | −16.3% / −18.5% | +11.6% | −2.9% |
| **только стоп-лосс** | **+0.5%** | **−9.9% / −13.1%** | **+26.9%** | **+3.6%** |
| возврат через сутки | −3.1% | −24.2% / −25.1% | +23.5% | −1.1% |
| сглаженный выбор | −1.3% | −10.3% / −13.4% | +12.6% | −1.6% |

| стратегия | валидация: net / Sharpe / просадка | WF среднее |
|---|---|---|
| **CatBoost + SL 3% (без тейка)** | +71.7% / 1.86 / −31.0% | **+4.3%** |
| CatBoost, подбор (SL 3% + TP 15%) | +25.9% / 2.36 / −8.3% | +1.1% |
| Ансамбль, подбор (TP 15%, возврат через сутки) | +71.8% / 1.86 / −26.7% | −4.3% |
| Ансамбль без стопов | +86.8% / 2.10 / −26.7% | −3.2% |
| FinRL | +31.0% / 2.84 / −8.3% | −1.1% |
| RL-позиция | +60.4% / 1.94 / −22.4% | не проверялась |
| LogReg, подбор | +13.9% / 0.73 / −23.1% | −7.4% |

**Вывод.** Стоп-лосс без тейка — лучшее правило по WF. Тейк-профит вреден в тренде: в бычьем-2 он
стоит 14–15 п.п. CatBoost + SL 3% — лучшая стратегия по WF, но почти пассивная: наивное
«buy & hold + стоп 3%» без модели даёт +2.8%.

### 4. `04_final_ensenble_with_trailing_stop.ipynb` — трейлинг-стоп

**Идея.** Заменить тейк-профит трейлинг-стопом (3/5/8/12% от лучшей цены сделки), чтобы не обрезать
тренд. Модели заново подобраны Optuna под новую целевую функцию.

| правило (среднее 4 табличных) | WF среднее | медвежий / медвежий-2 | бычий-2 |
|---|---|---|---|
| без стопов | −3.6% | −18.6% / −30.5% | +27.8% |
| подбор (= только стоп-лосс) | −1.9% | −10.2% / −19.5% | +28.3% |
| только трейлинг | −2.7% | −13.5% / −26.8% | +27.8% |
| сглаженный выбор | −2.0% | −8.9% / −20.7% | +27.8% |

| стратегия | валидация: net / Sharpe / просадка | WF среднее |
|---|---|---|
| CatBoost, SL 8% + трейлинг 12% | +55.8% / **2.68** / −11.2% | +2.1% |
| Ансамбль | +26.0% / 0.95 / −44.1% | −0.9% |
| RL-позиция | +42.0% / 1.67 / −21.6% | не проверялась |
| FinRL | +5.6% / 0.61 / −7.6% | −3.3% |

**Вывод.** Трейлинг действительно не обрезает тренд (+28% в бычьем-2 против +12% у тейка), но во
втором падении защищает хуже обычного стопа. Модели этого прогона слабее моделей ноутбука 3 даже
без стопов. Ни одна стратегия не обогнала buy & hold по net на валидации.

### 5. `05_final_ensenble_sltp_with_rl.ipynb` — RL управляет стопами

**Идея.** PPO-агент на каждом часе открытой сделки выбирает пару (стоп-лосс, тейк-профит) из сетки
5 × 5 по состоянию сделки и рынка. Направление позиции по-прежнему решает модель. Supervised-часть
воспроизводит ноутбук 3.

| правило (среднее 4 табличных) | валидация, медиана Sharpe | WF среднее | медвежий / медвежий-2 | бычий-2 |
|---|---|---|---|---|
| подбор | 1.30 | −3.1% | −16.3% / −18.5% | +11.6% |
| **RL управляет SL/TP** | **2.23** | −1.1% | **−7.9% / −12.3%** | +10.8% |

| стратегия | валидация: net / Sharpe / просадка | WF среднее |
|---|---|---|
| Ансамбль, RL-стопы | **+79.7% / 2.29 / −22.9%** | −4.9% |
| LogReg, RL-стопы | +30.7% / 2.16 / −13.1% | +0.6% |
| CatBoost, RL-стопы | +12.0% / 2.50 / −2.7% | +0.5% |
| RL на вершине ансамбля | +7.0% / 0.46 / −35.2% (в прошлом прогоне +39.1%) | не проверялся |

**Вывод.** RL-стопы лучше всех держат риск на валидации и в падениях, но на росте отдают больше всех.
На test-части dev преимущество не подтвердилось (лучше подбора только у одной стратегии из
четырёх). Мета-агент RL неустойчив к шуму входа.

### 6. `06_final_ensenble_with_binance_data.ipynb` — деривативы Binance

**Идея.** Добавить 35 признаков деривативного рынка из публичного архива Binance (`data/binance_raw/`
→ `data/btc_derivs_1h.csv`): open interest, фандинг, премия, базис, long/short, поток тейкеров,
прокси ликвидаций. Слой стопов и тейков здесь тот же, что в ноутбуке 1, — без стопов.

**Результат.** Отбор пережили 5 деривативных признаков. На кросс-валидации небольшой плюс во всех
абляциях (ROC-AUC +0.002…+0.003). В парном тесте «с деривативами / без» ДИ накрывает ноль у всех
моделей.

| стратегия | валидация: net / Sharpe / просадка | WF среднее |
|---|---|---|
| LogReg | — | −1.6% |
| Ансамбль | −3.3% / −0.24 / −16.9% | −2.1% |
| CatBoost | −22.0% / −0.47 / −57.4% | −7.1% |
| RL-позиция | +15.6% / 0.79 / −26.0% | не проверялась |
| FinRL | +7.1% / 0.50 / −29.6% | −2.0% |
| Ансамбль+ | −31.3% / −1.58 / −39.3% | не проверялся |

**Вывод.** Модели с деривативами реже держат лонг: в падениях теряют меньше, в росте почти ничего не
берут. Как признаки для прогноза деривативы денег не дали. Их стоит пробовать как режимный фильтр
в торговом слое.

### 7. `07_final_ensenble_with_sltp_lstm.ipynb` — LSTM

**Идея.** Добавить LSTM (окно 168 × 14 каналов ТА) как отдельную модель, в «Ансамбль+» и в новый
«Ансамбль + LSTM» (3 табличные модели + LSTM). Основа — ноутбук 3.

- **v1** (24 попытки Optuna на одном сиде): подбор выбрал шум. ROC-AUC 0.505, а CV Sharpe 2.07 на
  финальных сидах упал до 0.90.
- **v2** (150 попыток, 3 сида в каждой, фильтр ROC-AUC ≥ 0.515, 7 сидов в финальной модели): ROC-AUC
  0.529 на dev и 0.538 на валидации, прогнозы сидов согласованы (корреляция 0.73–0.96).

| стратегия | валидация: net / Sharpe / просадка | WF среднее |
|---|---|---|
| LSTM (v2) | −19.0% / −0.73 / −28.6% | −2.1% |
| Ансамбль + LSTM (v2) | +4.2% / 0.54 / −12.4% | +0.1% |
| Ансамбль + LSTM (v1, стоп 8%) | +51.1% / 2.20 / −15.3% | +2.2% |
| Ансамбль+ (7 моделей, v2) | −21.4% / −0.57 / −35.9% | не проверялся |

**Вывод.** LSTM v2 — первая модель, которая значимо улучшает ранжирование ансамбля: Δ ROC-AUC на
валидации +0.0073, 95% ДИ (+0.0044; +0.0102). Но в деньги это не превращается. Успех v1 был
удачей: шумная LSTM случайно сдвинула выбор стопа.

### 8. `08_final_ensenble_with_sltp_strategies.ipynb` — правила выхода

**Идея.** Поверх тех же моделей и сигналов, что в ноутбуке 3, проверить правила, которые не дают
отдать заработанное:
- **фиксация прибыли по времени**: закрыть сделку через N часов, если она в плюсе на X%;
- **лимит времени сделки**;
- **перевод стопа в безубыток**: когда цена ушла в плюс на T%, стоп переносится на цену входа
  + 0.2%.

Сравниваются 8 правил, подобранных на dev (4 750 вариантов выхода на стратегию). Раздел 26.1
отдельно проверяет ансамбль с безубытком и обязательным стопом 3–5%.

| правило (среднее 4 табличных) | WF среднее | медвежий / медвежий-2 | боковой / боковой-2 | бычий-2 | окна 4–6 |
|---|---|---|---|---|---|
| без стопов | −2.8% | −25.0% / −26.8% | −0.8% / −1.4% | +26.9% | −0.4% |
| **только стоп-лосс** | **+0.5%** | **−9.9% / −13.1%** | −2.7% / −2.9% | +26.9% | **+3.6%** |
| стоп + безубыток | +0.2% | −11.1% / −18.1% | +0.5% / −0.7% | +26.9% | +2.7% |
| стоп + выход по времени | −2.4% | −16.3% / −18.5% | −0.2% / −0.6% | +16.6% | −0.8% |
| стоп + безубыток + время | −1.8% | −10.9% / −18.1% | +1.3% / +0.4% | +14.3% | −1.1% |
| всё вместе | −2.1% | −12.6% / −18.5% | +0.1% / −1.5% | +13.2% | −2.3% |
| фиксированное правило (без подбора) | −0.2% | +2.3% / −3.9% | +0.2% / +1.1% | −0.1% | −1.0% |

| стратегия | валидация: net / Sharpe / просадка | WF среднее | окна 4–6 |
|---|---|---|---|
| **Ансамбль + SL 3% + безубыток 5%** (26.1) | +58.5% / 2.47 / −12.5% | **+4.2%** | +6.0% |
| Ансамбль + SL 4% + безубыток 3% (26.1, выбор по dev) | +57.4% / 2.48 / −12.3% | +2.0% | +5.3% |
| Ансамбль + безубыток 5% без стопа | **+101.9% / 3.22 / −11.4%** | −1.2% | −2.5% |
| CatBoost + SL 3% + безубыток 5% | +9.7% / 1.14 / −8.3% | **+4.8%** | +9.1% |
| CatBoost + SL 3% | +71.7% / 1.86 / −31.0% | +4.3% | +9.1% |

**Вывод.** Безубыток полезен на боковике и бесплатен в тренде, но только вместе с обычным стопом:
без стопа ансамбль потерял −33.6% в медвежьем-2. Фиксация прибыли по времени обрезает тренды и в
среднем вредит. Ансамбль с обязательным стопом и безубытком — самая сбалансированная стратегия
работы. CatBoost безубыток не подходит: после выхода по безубытку он долго не возвращается в рынок,
потому что его сигнал меняется 1–4 раза за всю валидацию.

Что видно из сравнения:

1. **Лучшее по валидации и лучшее по WF — разные стратегии.** Валидация — одно растущее окно, и на
   нём выигрывает тот, кто дольше держит лонг. WF с двумя падениями требует защиты капитала.
2. **Почти весь выигрыш даёт правило выхода, а не модель.** Простой стоп-лосс без тейка — главный
   рычаг всей работы. Тейк-профит, выход по времени и сложные комбинации обрезают тренды, на которых
   делается прибыль.
3. **CatBoost + SL 3% почти не отличается от наивного эталона** (+4.3% против +2.8%, разница набрана
   в одном окне). Модель там почти пассивна.
4. **Ансамбль + SL + безубыток — единственная активно торгующая стратегия**, у которой одновременно
   Sharpe на валидации выше рынка, просадка втрое меньше и положительный WF. Конкретный вариант
   «SL 3% + безубыток 5%» выбран задним числом из 12. Честный выбор по dev даёт +2.0%, так что
   реалистичная оценка — +2…+4% в среднем по окну.
5. **Ни одно преимущество не доказано статистически:** шесть окон по 45 дней и 1–50 сделок в окне.

### Итог

Кандидаты для paper trading — **CatBoost + SL 3%** и **Ансамбль + SL 3–4% + безубыток 3–5%**. Их
стоит запускать вместе с наивным эталоном «buy & hold + стоп 3%». Если модели за 1–2 месяца живой
торговли его не обгонят, их вклад сверх правила выхода нулевой. Перед реальными деньгами нужны:
фандинг в бэктесте, спред и проскальзывание, сохранение моделей и расписание переобучения.
