# Торговый бот BTC/USDT (Bybit testnet)

Бот торгует бессрочным фьючерсом **BTCUSDT (linear)** на Bybit testnet. Решения принимают
модели финального ансамбля. По умолчанию это **RL-агент на вершине ансамбля** (раздел 19.3): PPO,
который видит прогнозы LogReg, дерева решений и CatBoost.

## Состав

| файл | что делает |
|---|---|
| `trading_bot/features.py` | признаки ТА из разделов 2–7 ноутбука; формулы не менялись, новостей нет |
| `trading_bot/signals.py` | бэктест, торговый слой, RL-среда и `rl_rollout` из разделов 9–11 и 19 |
| `trading_bot/train.py` | обучение по протоколу ноутбука → `models/` |
| `trading_bot/strategy.py` | живой инференс: свечи → признаки → прогнозы → целевая доля капитала |
| `trading_bot/bybit_client.py` | REST-клиент Bybit v5 (подпись HMAC, свечи, баланс, позиция, ордера) |
| `trading_bot/bot.py` | цикл бота, исполнение ордеров, журналы в `logs/` |
| `trading_bot/selfcheck.py` | офлайн-проверка: признаки и решения бота совпадают с обучением |
| `mock_bybit/server.py` | локальная имитация Bybit v5 для проверки без доступа к бирже |

## Стратегии (`--strategy`)

- `rl_ensemble` (по умолчанию) — RL на вершине ансамбля. В наблюдении: ранги трёх прогнозов,
  их согласие, `ret_1`, `atr_14` и собственная позиция агента. Решение принимается раз в 24 часа,
  мёртвая зона 0.10, результат усредняется по трём сидам. Так настроено в ноутбуке.
- `rl_position` — RL-позиция (раздел 19.2): PPO на 18 отобранных признаках ТА.
- `ensemble` — среднее вероятностей трёх моделей плюс торговый слой (разделы 14 и 16).

Позиция агента лежит в [−1, +1]. На бирже это `позиция × капитал × --capital-frac / цена` BTC
(по умолчанию `--capital-frac 0.5`, плечо на бирже 2x). Рыночный ордер выставляется на разницу
с текущей позицией. Если нужно уменьшить позицию, ордер уходит с флагом `reduceOnly`.

## Запуск

```bash
./.venv/bin/python -m trading_bot.train          # ~4 мин: модели и отчёт models/report.json
./.venv/bin/python -m trading_bot.selfcheck      # проверка без биржи

# ключи лежат в .env (BYBIT_API_KEY / BYBIT_API_SECRET), шаблон — .env.example
./.venv/bin/python -m trading_bot.bot --roundtrip-test   # купить и продать минимальный лот
./.venv/bin/python -m trading_bot.bot --once             # одно решение модели и ордер сразу
./.venv/bin/python -m trading_bot.bot                    # постоянная работа, раз в час
./.venv/bin/python -m trading_bot.bot --every 1          # демо: решение на каждом баре
```

Журналы:
- `logs/bot.log` — ход работы;
- `logs/decisions.csv` — прогнозы моделей на каждом баре и целевая позиция;
- `logs/trades.csv` — ордера: id, статус, цена, комиссия, позиция до и после;
- `logs/bot_state.json` — позиции агентов по сидам, чтобы бот продолжал работу после перезапуска.

## Проверка

1. **`selfcheck`.** Признаки, посчитанные по окну из 2000 последних баров, совпадают с
   признаками по всей истории (расхождение 1e-8). Пошаговые решения бота за 10 суток
   совпадают с пакетным `rl_rollout` агентов (расхождение 0).
2. **Имитация биржи** (`mock_bybit/server.py`). Сервер проверяет подпись запросов так же,
   как Bybit, и исполняет рыночные ордера. На нём прошли:
   - roundtrip минимального лота;
   - 10 суточных решений `rl_ensemble` с перемоткой истории: 10 исполненных ордеров, покупки
     и reduce-only продажи;
   - `rl_position` и `ensemble`;
   - переворот в шорт и закрытие;
   - отказ `10004` при неверном секрете.

   Журналы этого прогона лежат в `logs/mock_demo/`.

## Качество моделей

Бот обучен на всём `data/btc_1h.csv` (до 20.07.2026), а не на обрезанном по новостям ряде
ноутбука. Поэтому валидационное окно другое: 22.09.2025 – 19.07.2026. На нём BTC упал на 43%.
Результаты при комиссии 0.1% (`models/report.json`):

| стратегия | net | Sharpe | сделок | средняя экспозиция |
|---|---|---|---|---|
| Buy & Hold | −42.7% | −1.26 | 1 | 1.00 |
| DecisionTree + слой | −5.9% | 0.06 | 140 | 1.00 |
| CatBoost + слой | −29.3% | −0.70 | 27 | 1.00 |
| RL-позиция | −42.5% | −1.71 | 252 | 0.68 |
| RL на вершине ансамбля | −44.9% | −1.75 | 255 | 0.78 |

Агенты обучены на растущем dev-периоде и держат в основном лонг (+0.6…+0.8), поэтому на
падающем рынке теряют примерно как рынок. Это согласуется с выводами ноутбука (раздел 24,
walk-forward): устойчивого преимущества в разных режимах рынка нет. Бот подходит для
демонстрации торговли на testnet, но не для реальных денег.

Отличия от финального ансамбля:
- нет новостных признаков: живой ленты нет, а в ноутбуке отбор пережил только
  `news_count_168`;
- нет TimesNet, TSMixer и TimesFM: мета-агент видит три табличные модели, а не шесть;
- гиперпараметры моделей и настройки RL (PPO, k=24, δ=0.10) взяты из ноутбука, заново не
  подбирались.
